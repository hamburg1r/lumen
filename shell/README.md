# Quickshell status and auth dialogs (Phases 0–2)

`shell.qml` draws a small top-left indicator and polls `Ping` every two seconds. It also polls `org.lumen.Auth` through `lumen-auth-gui` every second and displays a password dialog for pending sudo challenges. Passwords travel to the helper over stdin, never command arguments. A separate Quickshell Polkit agent registers for the shell's logind session and conducts Polkit's PAM conversation in its own dialog; it does not route candidate secrets through the sudo broker. Run `nix run .#lumen-shell` from a Wayland session. `quickshell ipc --path shell/shell.qml call status connection` reports the indicator state, and `... call status polkit` reports Polkit registration. A competing Polkit agent prevents registration; see `docs/phases/02-polkit.md`. Full bar/media UI belongs to later phases.
